# PRÀCTICA — CORREGIR I AMPLIAR DOCUMENTS XML



## Procediment

Obri els fitxers en l’editor. Abans d’utilitzar el comprovador XML en línia, proposa una primera correcció. Després, interpreta els missatges, corregix i torna a comprovar.

Conserva les dades originals. No elimines registres per fer desaparéixer errors.

Crea un arxiu **`respostes.md` dins del projecte**. Organitza’l amb un apartat per exercici i escriu-hi:

- una explicació breu per cada tipus d’error: **problema → correcció → regla aplicada**;
- la resposta a la pregunta de raonament de cada exercici.

> Sense una DTD o un esquema, la ferramenta comprova si el document està **ben format**. Un error pot provocar diversos missatges, i la línia indicada no sempre coincidix amb el lloc on s’ha originat.

## 1. Persona — demostració conjunta

**Fitxer:** `01_persona.xml`.

Completa el tancament que falta i ajusta la indentació a la jerarquia real. Conserva les dos professions.

**Pregunta de raonament:** Canviaria el pare de `<cognom>` si modificares només la seua indentació, sense canviar les etiquetes? Justifica la resposta.

## 2. Clients i comandes — localitza i amplia

**Fitxer:** `02_clients.xml`.

1. Corregix els errors sense eliminar clients ni comandes. Els identificadors dels clients han de continuar sent `c01`, `c02` i `c03`.
2. Localitza la comanda `C104` i afig una segona línia de compra dins de `<linies>`:

| Dada | Valor |
|---|---|
| Codi del producte | `P50` |
| Producte | Ratolí sense fils |
| Quantitat | `2` |
| Preu unitari | `24.90` |
| Moneda | `EUR` |

3. Comprova el resultat.

**Pregunta de raonament:** Explica en una frase per què el nom de l’empresa i el nom de la persona de contacte poden utilitzar l’etiqueta `<nom>`.

## 3. Llibres — reconstruïx i amplia el catàleg

**Fitxer:** `03_llibres.xml`.

1. Corregix els errors. Els huit llibres han de quedar dins d’una única arrel `<cataleg>`. `<autor>` contindrà `<nom>`, l’edició es representarà amb `<edicio>` i cada `<portada>` serà un element buit amb l’atribut `fitxer`.
2. Localitza `l04` i consulta el seu gènere. Afig al final del catàleg un llibre del mateix gènere, amb la mateixa estructura i estes dades:

| Dada | Valor |
|---|---|
| Identificador | `l09` |
| Títol | Fahrenheit 451 |
| Autor | Ray Bradbury |
| Edició | `1` |
| Idioma | Valencià |
| Format | Paper |
| Preu | `15.90`, en `EUR` |
| Descripció | Una societat perseguix els llibres. |
| Portada | `fahrenheit.png` |

3. Comprova que el document conté nou llibres i continua ben format.

**Pregunta de raonament:** Si les etiquetes estan ben tancades, el comprovador detectaria que has afegit `l09` dins de `l08`? Justifica si eixa estructura representaria correctament el catàleg.

## 4. Música — corregix i millora un model

**Fitxer:** `04_musica.xml`.

1. Corregix els errors de sintaxi. En cada àlbum, `<publicacio>` ha de contindre `<any>` i `<segell>`.
2. Localitza l’àlbum `a03` i modifica el seu model:
   - conserva `id` com a atribut;
   - passa el títol de l’àlbum i l’artista a elements fills;
   - substituïx els atributs numerats de `<cancons>` per elements `<canco>`, cadascun amb `<titol>` i `<duracio>`.
3. Conserva totes les dades i comprova el resultat.

**Pregunta de raonament:** Justifica en una frase per què el nou model permet afegir cançons més fàcilment.

## Lliurament

Els quatre XML corregits i ampliats i l’arxiu `respostes.md` amb les explicacions i les respostes.
